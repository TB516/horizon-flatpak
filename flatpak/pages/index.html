Horizon Flatpak

Unofficial package for x86_64 Linux

Horizon is a rewrite of Minecraft: Java Edition in Rust. You need a Microsoft account that owns Java Edition. Neither Horizon nor this package is approved by or associated with Mojang or Microsoft.

Install Horizon

Accept the prompt to add the Horizon repository for updates and to keep the app available to reinstall after uninstalling.

Or install Horizon from a terminal:

flatpak install --user https://horizon.thomasberrios.com/dev.playhorizon.Launcher.flatpakref

You can also add the repository separately and install Horizon later from your software store.

Source and release notes are available on GitHub.
